1. What do you want to collect?

Reddit is one endlessly scrolling list, so it's counted in posts: each post's title and question is saved (comments, image/link posts and ads are skipped). Files are named by post number, e.g. Reddit_Posts_00001-00500.txt. Reddit shows at most about 1,000 posts per list – choose another list (Hot / Top) to reach different posts.
Reddit API access – recommended; fixes "blocked by network security"

Set up your free Reddit API key (about 2 minutes)
  1. Log in to Reddit in your normal browser and open reddit.com/prefs/apps.
  2. Click create another app… (or are you a developer? create an app…).
  3. Name: anything, e.g. my-post-collector. Choose script. Redirect uri: http://localhost:8080. Click create app. If Reddit asks you to accept its API terms or register, follow its steps.
  4. Copy the client ID (the short code under “personal use script”) and the secret into the boxes below.
The key is stored only on this computer (in the app's data folder). Reddit's free API is for personal, non-commercial use.
